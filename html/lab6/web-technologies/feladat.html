Feladat

Készíts egy olyan HTML dokumentumot, mely a Web technológiák kurzuson eddig tárgyalt három vagy több számítógépes nyelvet mutat be röviden, mint például a Markdown, XML, JSON, CSS vagy HTML.

A dokumentumban minden egyes nyelvet egy olyan <article> elem kell, hogy ábrázoljon, melynek az alábbi információkat kell tartalmaznia:

  • A nyelv neve címsorként megjelenítve.
  • A nyelv nagyon tömör (egy mondatos) leírása.
  • Hiperlink(ek) a nyelv specifikációjára (specifikációira).
  • Egy jellemző kódrész, mely a nyelv használatát szemlélteti, ehhez a <pre> elemet kell használni. Legalább egy kódrészben szerepelnie kell "<" és/vagy "&" karakter(ek)nek.

A dokumentumnak tartalmaznia kell egy olyan tartalomjegyzéket is, mely minden egyes nyelv <article> elemére tartalmaz egy hiperlinket.

Az oldal alján meg kell, hogy jelenjenek a felhasználási feltételek, licencként a Creative Commons “Attribution 4.0 International” licencet használd.

A dokumentumnak ráadásul tartalmaznia kell az utolsó módosítási dátumot.

A dokumentum esztétikusan kell, hogy megjelenjen a böngészőben.

További teendők

A kódrészeket automatikusan generált sorszámokkal jelenítsd meg, azaz minden kódsornak legyen egy száma. A feladat megoldásához JavaScript szükséges.
